B2 — Unity visualization of the agent (side-quest)

⬜ Deferred, not dropped. Design only — jay's idea, 2026-08-06. A Unity scene that shows the agent acting: it wakes, checks a price board, mostly shrugs and goes back to sleep, and after expiry walks to a gate that no longer opens. The value beyond fun is that it makes the enforcer physical — in a journal a rejection is a red word, in a scene it is a gate that will not move.

Two rules that survive from the design and should not be re-litigated: Unity is a dumb renderer (it gets journal rows via SendMessage and never touches a chain, a key, or an RPC — a second path to the chain could disagree with the journal, and the journal is the record), and it lives behind a toggle on /live/agent, not its own route, for the same reason.
