Known gotchas (already found — don't rediscover them)

  • Chainlink feeds on a fork are frozen at the fork block; no oracle updates them. feeds.ts writes aggregator answers (admin only). Oracle-dependent integration tests stay on Sepolia.
  • MetaMask's 7715 popup (wallet_requestExecutionPermissions) does not engage on 313370 — it only works on chains MetaMask lists. Use the plain EIP-712 Delegation path (rabbit already does) and the own dev wallet on the devnet; keep the popup demo on Sepolia.
  • Fork lazy loading is slow on first touch: the framework deploy took 2 m 28 s on a fresh fork vs 0.24 s on a plain node. Pin the block, keep the node warm, don't rerun the seed casually.
  • --block-time 1 means transactions are not instamined; every script must wait for receipts.
  • The kit hardcodes no chain list and no addresses; the Registry is how services find the framework.
