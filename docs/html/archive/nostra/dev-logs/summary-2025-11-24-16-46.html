Changes

1. Portfolio Summary (Task-1)

  • File: api/src/routes/users.ts
  • Changes:
    • Enabled GET /api/users/:address/balance to fetch USDC balance from the blockchain (MockUSDC contract).
    • Added GET /api/users/:address/portfolio to return a summary including cash balance and trade statistics.
    • Note: P&L calculation currently returns placeholders or basic stats. Full historical P&L would require a more complex historical data tracking system.

2. Positions Tab (Task-2)

  • File: api/src/routes/redemption.ts (Existing)
  • Status:
    • The existing GET /api/redemption/positions/:userAddress endpoint already returns comprehensive position data, including:
      • Market details
      • Outcome balances (shares)
      • Estimated value (based on current price or resolution payout)
      • Claimable status
    • This endpoint is suitable for populating the "Positions" tab.

3. Claims Tab (Task-3)

  • File: api/src/routes/redemption.ts (Existing)
  • Status:
    • The GET /api/redemption/positions/:userAddress endpoint returns a claimable flag for each position.
    • The POST /api/redemption/claim endpoint handles the claim logic, verifying resolution status and preparing the transaction for the frontend.
    • These endpoints cover the requirements for the "Claims" tab.

4. Open Orders Tab (Task-4)

  • File: api/src/routes/orders.ts
  • Changes:
    • Added GET /api/orders/user/:userAddress endpoint.
    • This endpoint fetches all OPEN or PARTIALLY_FILLED orders for a specific user, including market and outcome details.
    • This allows the frontend to display a list of the user's active orders.
