# ETC (misc / trivial experiments)

**Goal:** a catch-all menu (`/etc`) for small, low-stakes experiments and one-off tests that
don't deserve their own top menu. Keeps the main nav clean — trivial things land here instead of
cluttering Home, Portfolio, etc.

## Features
- [ ] **SimpleX Chat test** — try [SimpleX Chat](https://simplex.chat) (privacy-first messenger,
  no user IDs or phone numbers). Smallest cut: embed or link a SimpleX chat invite and confirm a
  message round-trips. Decide later whether it graduates to its own feature.

## Conventions
- Items here are deliberately small. If one grows, **promote it** to its own menu + feature doc
  and remove it from this list.
- Add new trivial experiments as checklist items under **Features** above.
