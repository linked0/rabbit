### Deploy: fix Cloud Build failure (pnpm ignored builds + prisma generate)
First Cloud Run deploy failed at `pnpm install --frozen-lockfile` with **ERR_PNPM_IGNORED_BUILDS**:
pnpm 11 blocks `@prisma/*` build scripts by default and exits 1. They're approved locally via
`pnpm-workspace.yaml` (`allowBuilds:`), but the Dockerfile copied only `package.json` +
`pnpm-lock.yaml` before install, so the approval was missing in the container. Fix (`Dockerfile`):
(1) also copy `pnpm-workspace.yaml` before install; (2) `RUN pnpm exec prisma generate` after
`COPY . .` (schema must exist; `lib/db.ts` instantiates `PrismaClient` at import). Verified by a
local `docker build --target builder` — install + generate + `pnpm build` all pass. Re-deploy via
`./scripts/deploy.sh` (`--source .` uploads the working tree). Why: get the first cloud deploy to
build green. **Open**: cloud `DATABASE_URL` still points at localhost (DB features won't persist
until pointed at Cloud SQL); add the printed OAuth redirect URI after a successful deploy.
