### The Pages site had been frozen for 11 days, because of a private submodule

- **Cause:** jay, with a phone screenshot of `docs/features/README.md` rendered in the GitHub app: "the feature designs card on index page does not show the real content like this". The card on alice's landing page opens `linked0.github.io/rabbit/html/docs/features/README.html`, and that page was serving something smaller and older than the file on disk — 25,922 bytes against 49,688.
- **Reasoning:** the card was fine and the generated HTML was fine; both were committed and pushed. The Pages **build** was the thing that had stopped. Every build since **2026-09-11** had the status `errored` with the unhelpful message "Page build failed", so the site kept serving the last successful copy — eleven days of edits, invisible. The cause is that the legacy Pages builder clones the repository **with its submodules**, and `games/jayverse-game` is a **private** repository it cannot authenticate to. Nothing about the failure mentions submodules, which is why it sat unnoticed; the only visible symptom was content that quietly stopped changing. Note that `.nojekyll` would **not** have fixed it — the submodule fetch happens during checkout, before Jekyll ever runs.
- **Change:** `.github/workflows/pages.yml` publishes `docs/` through Actions instead, with `actions/checkout` at its default `submodules: false` — the whole fix is not asking for something that was never needed to publish docs. Jekyll was dropped with it, deliberately: every `.md` in the repo is already rendered to `docs/html/` by `scripts/generate-docs-html.mjs`, and every link in the site points at that output, so Jekyll was doing no useful work while being one more thing that could break. `docs/.nojekyll` makes that explicit. The Pages source was switched from the legacy builder to `build_type: workflow`.
- **Result:** the workflow ran green and the features page is **49,245 bytes** with the "Three end-to-end scenarios" section and the rails-shortlist link present, matching the source. All four rabbit-backed cards on alice's index (Feature Designs, Current Plan, History, Docs) return 200 with current content, and today's three history entries now appear in the live history index. Alternatives not taken, both jay's call: make `jayverse-game` public, or drop the submodule from this repo.
